CodasSol Clean Reinstall v0.2.0-rc.1 — PRE-RELEASE

Extract the ZIP fully to a new folder outside the old CodasSol runtime.
Double-click CLEAN-REINSTALL.cmd as the SAME normal Windows user (not administrator).
Review the exact scope, type CLEAN, choose one existing project folder, then INIT.
The DevSpace initializer is interactive. For remote access, type PAIR and enter
YOUR HTTPS Router origin and current pairing token. PAIR.cmd can do this later.

Only the three verified CodasSol Standalone V02 tasks/processes are stopped.
Old runtime is quarantined when possible; locked/access-denied files remain.
No permanent deletion, ACL changes, antivirus changes or shared .devspace edits.
Old backups, recovery siblings and old pairing files are retained, but never
loaded by the new NodeCleanR1 runtime. This is a fresh identity, not a rollback.
Do not rerun over a partial NodeCleanR1 installation; failures preserve evidence.

Requires Windows x64, Windows PowerShell 5.1, network access to npm for pinned
DevSpace 1.1.0-beta.4 and its dependencies. Private Node 22.23.3 is included.
Dependency installation may take up to 10 minutes and prints ongoing progress.
If timeout occurs, possible dependency build children are retained, not broadly killed.
This is NOT unattended deployment. Automated Windows CI is not physical acceptance.
Original backend-start failure cause is unconfirmed. Reboot, sleep, disconnect,
new pairing and actual remote execution on your computer remain unverified.
Source commit and file hashes are recorded in release-manifest.json.
